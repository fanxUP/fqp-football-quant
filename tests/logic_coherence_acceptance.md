# FQP 逻辑衔接验收清单

## 本地个人模式

- [ ] 系统可在无登录模式打开。
- [ ] 可选本地 PIN 不影响核心任务。
- [ ] 不存在必须选择用户/租户才能使用的页面。

## 模块化

- [ ] 关闭可选模块不会导致核心系统崩溃。
- [ ] 关闭模块后菜单隐藏，历史数据可查。
- [ ] 删除模块前必须备份。
- [ ] 核心模块不可关闭。

## 数据流

- [ ] 官方比赛只能来自官方源。
- [ ] 第三方特征不能新增官方比赛。
- [ ] 所有推荐绑定赔率快照、特征快照、模型版本。
- [ ] 赛后实际首发不能污染赛前预测。

## 推荐与资金

- [ ] 500 元为上限，不强制用满。
- [ ] 系统可生成“不推荐”结论。
- [ ] 模拟账户与实票账户分离。
- [ ] 用户偏差可统计。

## UI

- [ ] 首页使用红黑科技风。
- [ ] 风险状态清晰可见。
- [ ] 关键面板有最后更新时间。
- [ ] 10 秒内能判断今日是否可推荐。

## Codex

- [ ] Codex 不能直接执行生产迁移。
- [ ] Codex 失败不影响 scheduler/worker。
- [ ] Agent 有路径权限边界。
