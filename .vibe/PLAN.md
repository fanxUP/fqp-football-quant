# P111-01 实施计划

1. 复用 P106 的 `TrainingManifest` / `training_manifest_sha256`，不建立第二份数据集选择规则。
2. 输入中显式提供 canonical competition-season 与逐场 neutral 场地事实，并附证据摘要和首次可用时间；拒绝猜赛季、猜中立场或混季训练。摘要绑定内容但不证明来源权威。
3. 按结果发布时间过滤到截止时间，并按开球日期应用指数半衰期权重。
4. 以 Poisson 攻防项、赛季基准进球率、中性主场优势先验及 L2 小样本收缩拟合单一可解释挑战者。
5. 对升班马仅接受显式证据映射和可用时间；未知身份仍使用中性先验并标明覆盖，不从俱乐部名称/联赛名推断。
6. 预测只返回研究结果；使用既有比分矩阵工具，记录 manifest、季赛事实、配置和源码摘要的确定性哈希。完整 P111 的 artifact/run/evaluation 持久化和影子消费者仍是后续切片。
7. 用固定样本验证关键边界；下一切片接入 P106 运行/评价框架之前，先确认本切片审查结果。
