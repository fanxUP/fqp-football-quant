# P108-05A / P111 / P114：回填期间可独立推进的工程切片

## 目标

让可信的 P104 官方赛果观测可按提交可见时间用于训练/回测；让 P108 球员输入即使不完整也能留下可审查回执，但不改变正式概率；保留 P111 动态球队候选的可执行实现与严格点时输入契约。该批只证明工程行为，不宣称真实模型效果通过。

## 范围

- P108-05A：保存球员投影摘要与 ready/withheld 证据；当前候选始终 `withheld`、`probabilities=null`、`applied_features=[]`。
- P114：实时官方赛果存储 P104 来源观测及提交可见回执；训练 manifest 和回测只读取 cutoff 前可见的修订。没有回执的历史行保持排除，不用文件时间或回填时间补造。
- P111：使用既有 P106 manifest/run/evaluation 框架与合成样本验证动态球队候选；真实拟合和效果比较需要合格数据。
- 仅本地固定样本与专用 loopback PostgreSQL 16；不连接生产库、付费 API、NAS 正在运行的 Titan SQLite。

## 验收边界

1. 相关固定样本和隔离 PostgreSQL 回归通过，覆盖 cutoff 可见性、未来修订隔离、回执失败与球员概率隔离。
2. Ruff、格式、mypy、编译、diff、scope 与 budget 通过。
3. 发布前须完成适用的独立复核、GitHub exact-head CI、服务器当前状态/回滚材料/受保护 smoke，并按部署脚本执行；本地 PASS 不代表生产验收。
4. P108/A108、P111 真实模型效果、P114/A114 和 P115 保持独立状态；缺少可信身份、标签可用时间或同一时点赔率时不得判通过。

## 当前限制

已审 NAS CSV 只能支持来源内部候选映射，缺少规范球员身份、可靠来源时间和分钟；P114 已记录样本的来源发布时间/取得时间及配对赔率仍不足。Titan SQLite 当前由回填进程持有，禁止并行读取。
