# 赔率走势第三方品牌对照

## 目标

在每场赔率走势卡片中，将中国体彩放在首行，并按用户指定顺序展示从本地归档映射出的 8 个第三方品牌：Betfair、皇冠、易胜博、澳门、立博、威廉希尔、平博、bet365。第三方数据只用于全场胜平负对照。

## 实施范围

- 后端仅从已发布的 `football_history` 数据读取，按已确认的体彩/球探赛事关联及唯一来源身份匹配；不写数据库、不调用外部数据源。
- 在赔率走势接口上以可选参数返回第三方胜平负初始/末次赔率；身份不明确、数据缺失或查询超时均不伪造数据。
- 前端各来源一行，体彩固定第一；第三方缺失保留品牌行并标明“暂无快照”。其他体彩玩法不展示/误用胜平负第三方赔率。
- 不新增迁移、依赖、计划任务或预测模型接入。

## 验收

1. 后端参数绑定和品牌映射有固定样本回归。
2. 前端验证体彩与八个品牌的行顺序、缺失占位和非胜平负玩法隔离。
3. 后端定向回归、前端定向回归、Ruff、mypy、TypeScript、生产构建与 `git diff --check` 通过。
4. 独立只读代码审查、GitHub `main` 精确提交 CI 通过。
5. 无数据库迁移时按正式发布脚本部署；服务器健康与只读保护路由 smoke 通过。
