# 01_PRD_产品需求文档

## 1. 用户角色

### 个人长期用户
每天查看官方赛程、模型推荐、预算建议；线下自购后上传票据；次日查看复盘；每周/月查看总结。

### 系统管理员
维护数据源、球队映射、模型版本、风控参数、任务调度、异常告警。

### 研究人员/开发人员
复现论文模型、训练模型、回测策略、优化资金分配。

## 2. 功能模块

### 首页 - 今日看板
- 今日官方比赛数；
- 可分析比赛数；
- 数据源健康状态；
- 今日预算上限；
- 建议投入金额；
- 风险模式；
- 推荐票单数量；
- 待上传实票数量；
- 昨日复盘摘要。

### 官方赛程页
- 按业务日期展示官方场次；
- 显示联赛、主队、客队、开赛时间、停售时间；
- 显示开售玩法；
- 显示最新SP与赔率变化；
- 显示是否允许推荐。

### 比赛详情页
- 官方基础信息；
- 赔率快照曲线；
- 市场概率与去水方法对比；
- Poisson/Dixon-Coles比分矩阵；
- 各玩法概率；
- 风险标签；
- 推荐状态。

### 今日推荐页
- 今日预算上限500元；
- 建议使用预算；
- 主策略池、价值池、防守池、实验池分配；
- 每张票单的比赛、玩法、选项、SP、模型概率、市场概率、EV、金额、风险等级；
- 不推荐原因提示。

### 实票上传页
- 上传彩票照片；
- 手动录入票面信息；
- OCR识别结果确认；
- 绑定模型模拟票；
- 偏差标签；
- 等待结算状态。

### 复盘中心
- 日报、周报、月报；
- 模拟账户 vs 实票账户；
- 玩法、联赛、赔率区间、模型版本表现；
- 错因归因；
- 下周期调整建议。

### 回测中心
- 选择模型版本、时间范围、联赛、玩法、赔率区间、EV阈值、资金规则；
- 输出资金曲线、ROI、最大回撤、Brier、Log Loss、CLV。

### 传统足彩中心
- 14场胜负彩/任选9期号；
- 单场概率；
- 胆拖配置；
- 注数成本；
- 冷门覆盖；
- 蒙特卡洛模拟命中概率。

## 3. 非功能需求
- PostgreSQL 数据库；
- macOS 本机原生开发与长期运行，不依赖 Docker Desktop（详见 `54_本机运行与DockerDesktop弃用说明.md`）；
- 数据快照不可覆盖；
- 任务失败自动重试；
- 全量日志和审计；
- 每日备份；
- 推荐生成耗时小于60秒；
- 首页加载小于3秒；
- 数据源异常必须明显展示。
