# 12_回测中心与模型评估

## 回测目标
判断某个模型、玩法、资金策略是否长期有效。

## 回测维度
时间范围、联赛、玩法、赔率区间、EV区间、模型版本、风险等级、快照时间、资金池、过关方式。

## 指标
- 样本量；
- 命中率；
- ROI；
- Brier Score；
- Log Loss；
- 最大回撤；
- 最长连亏；
- 平均赔率；
- CLV；
- 资金曲线。

## Walk-forward规则
1. 用过去数据训练；
2. 预测未来窗口；
3. 滚动更新；
4. 每次保存模型版本；
5. 禁止使用未来数据。

## 模型上线门槛
- 样本量不足1000场不允许得出强结论；
- 概率指标不能明显劣于市场基线；
- 资金曲线不能靠少数极端高赔支撑；
- 最大回撤必须在可接受范围。
