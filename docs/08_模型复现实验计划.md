# 08_模型复现实验计划

## 实验0：官方SP市场概率基线

### 输入
官方赔率快照、赛果。

### 步骤
1. 计算1/SP；
2. 对同一玩法选项归一化；
3. 计算 Brier Score、Log Loss；
4. 按联赛、赔率区间、玩法分组。

### 验收
输出 market_baseline_report.md，作为所有模型对照组。

## 实验1：Maher Poisson

### 输入
历史比分、主客队、联赛、比赛时间。

### 步骤
1. 估计球队进攻/防守强度；
2. 估计主场优势；
3. 生成 lambda_home、lambda_away；
4. 生成比分矩阵；
5. 派生玩法概率；
6. 与官方SP市场概率对比。

### 验收
如果概率指标不优于市场基线，不进入正式推荐，只作为特征模型。

## 实验2：Dixon-Coles

### 输入
历史比分、时间衰减参数、低比分修正参数。

### 步骤
1. 基于Poisson加入rho修正；
2. 对0:0、1:0、0:1、1:1进行修正；
3. 调参时间衰减；
4. 对比平局校准。

### 验收
至少在平局预测或低比分校准上优于Maher基线。

## 实验3：Shin/Power概率转换

### 输入
同一玩法所有官方SP。

### 步骤
1. 计算简单归一化概率；
2. 计算power概率；
3. 计算shin概率；
4. 按赔率区间评估Brier。

### 验收
明确每个玩法采用哪种去水方法。

## 实验4：Kelly资金模拟

### 策略组
固定20元、固定50元、1/8 Kelly、1/4 Kelly、EV分层、连续亏损降仓。

### 输出
ROI、最大回撤、最长连亏、资金曲线、最差月份、破产概率。

### 验收
资金策略不以最高收益为唯一标准，必须同时控制回撤。
