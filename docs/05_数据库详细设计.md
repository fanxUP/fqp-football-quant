# 05_数据库详细设计

数据库采用 PostgreSQL。核心要求是：快照不可覆盖、模型版本可追溯、推荐可重算、实票可审计、回测不穿越。

## 核心表组

### 官方数据
- official_matches
- official_markets
- official_odds_snapshots
- official_results
- official_crawl_logs

### 数据治理
- teams
- team_aliases
- leagues
- league_aliases
- match_feature_snapshots

### 模型研究
- research_papers
- model_versions
- odds_probability_conversions
- score_distribution_snapshots
- model_predictions
- model_committee_votes

### 推荐与资金
- daily_budget_plans
- simulation_tickets
- simulation_ticket_items
- bankroll_accounts
- bankroll_transactions
- recommendation_shutdown_events

### 实票与复盘
- real_tickets
- real_ticket_items
- ticket_settlements
- daily_reviews
- weekly_reviews
- monthly_reviews
- prediction_error_analysis

### 传统足彩
- football_pool_issues
- football_pool_issue_matches
- football_pool_combinations

## 关键约束
- official_matches 使用 business_date + official_match_code 唯一；
- odds_snapshot 不允许 update sp_value；
- prediction 必须绑定 model_version_id 和 odds_snapshot_id；
- ticket_item 必须绑定 match_id；
- real_ticket 修改必须进入 audit_logs；
- backtest_run 必须记录 data_cutoff_time。

完整建表 SQL 在 sql/ 目录。
