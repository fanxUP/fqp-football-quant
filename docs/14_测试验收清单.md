# 14_测试验收清单

## 官方数据验收
- 可采集官方赛程；
- 可保存玩法和SP；
- 可保存多时间点快照；
- 官方源异常时报警；
- 不允许第三方比赛进入官方表。

## 模型验收
- 市场概率计算正确；
- 去水方法输出概率和为1；
- Poisson比分矩阵和为1；
- Dixon-Coles低比分修正可开启/关闭；
- 模型预测绑定版本；
- 回测不穿越。

## 推荐验收
- 每日预算不超过500；
- 单票不超过100；
- 单场暴露不超过150；
- 熔断时不出单；
- 推荐绑定快照和模型版本。

## 实票验收
- 可上传照片；
- 可手动录入；
- 可绑定推荐；
- 可自动结算；
- 可统计用户偏离。

## 报表验收
- 日报自动生成；
- 周报自动生成；
- 月报自动生成；
- 可输出错因归因；
- 可导出PDF/Excel。
