# 14. 当前实现的验收检查范围

本页是文字检查清单，实际结果来自执行记录。

1. 按本次任务授权选择相关测试和验证，记录环境、提交、命令、退出码与未运行项。原因：清单存在不等于测试已经执行。
2. 官方赛程、玩法、赔率和赛果验证来源边界，重复采集不覆盖历史赔率。原因：预测与票据依赖可追溯的官方证据。
3. 概率计算验证合法范围、归一化、模型版本及有效预测所需快照。原因：这些字段决定预测能否作为可用结果。
4. 历史预测与回测验证时间边界。原因：未来数据会使历史表现失真。
5. 虚拟票单按当前组合、倍数与竞赛账本规则验收。原因：虚拟竞赛按当前代码分配额度，历史固定阈值不代表现有行为。
6. 实票验证上传/录入、结算及修改删除后的审计记录，区分真实与虚拟来源。原因：票据变更会影响复盘和竞赛统计。
7. 报表只验收已有接口和页面支持的能力，自动化按实际配置检查。原因：历史设计中的导出或生成目标不能当作现成功能。
8. 发布准备以实际 CI 与目标提交核对，运行时就绪和回退另行记录。原因：本地静态检查不能证明已部署版本正常。

自动化检查来源：`.github/workflows/ci.yml`。开发与发布流程见 [33 号规范](33_自动测试代码审查与部署交付流程.md)。
