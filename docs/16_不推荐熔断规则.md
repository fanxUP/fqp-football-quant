# 16_不推荐熔断规则

系统必须具备“不推荐”的能力。长期程序不是每天硬出单，而是识别不适合参与的日期、比赛和玩法。

## 全局熔断
- 官方数据源不可用；
- 官方赛程缺失；
- 赔率快照缺失率超过阈值；
- 赛果结算异常；
- 数据库写入失败；
- 连续亏损触发防守或只模拟。

## 比赛级熔断
- 数据完整度低于80；
- 赔率波动剧烈且无解释；
- 模型委员会分歧大；
- 临场伤停缺失；
- 小联赛样本不足；
- 官方玩法关闭。

## 票单级熔断
- 单票金额超限；
- 单场暴露超限；
- 串关相关性过高；
- 高风险选项过多；
- 不确定性惩罚后EV不足。

## 输出格式
熔断必须说明原因，例如：今日不建议实票，原因是官方赔率快照缺失3场、模型分歧较大、近期连续回撤进入防守模式。
