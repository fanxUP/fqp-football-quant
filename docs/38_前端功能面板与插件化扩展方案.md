# 38. 前端页面与面板维护

## 当前实现

导航数据来自 `GET /api/ui/panels`；页面组件和路由在 `apps/frontend/src/App.tsx` 中显式声明；匹配逻辑位于 `core/router.ts`，使用 hash 路由。

## 保留规则

1. 修改导航时更新最终面板注册表，核对对应模块和实际页面路由。原因：配置可改变导航，但不会自动注册组件。
2. 跨页面传递赛事等标识时使用已有路由参数和 API Client。原因：稳定标识可隔离各页面的数据读取，避免直接调用另一页内部函数。
3. 按查询身份处理加载、空数据、错误和晚响应。原因：切换比赛或筛选条件时不能展示上一个查询的结果。
4. 沿用主题 Token、现有共享组件和二维回退。原因：应用支持多主题、移动端和 WebGL 不可用场景。
5. 模块关闭后的导航与深链接行为按实际入口检查。原因：面板隐藏不能代替 API 权限或自动移除静态路由。
6. 按任务授权验证相关交互、类型和构建，并记录未执行项。原因：页面能注册不代表数据加载和交互已经正确。

当前目录是 `apps/frontend/src/pages/`、`shared/`、`app/`、`core/` 和 `theme/`。历史设计中的 Global Query Cache、Event Bus、统一前端模块目录及自动路由注册没有对应通用实现。
