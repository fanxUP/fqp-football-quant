# 07_论文依据与模型白皮书

## 为什么要论文驱动
如果模型只靠经验，短期可能看起来有效，但无法长期迭代。论文驱动的意义不是照搬论文，而是明确：模型假设是什么、输入是什么、输出是什么、局限是什么、如何回测、是否适合中国竞彩网官方SP环境。

## 论文到模型映射

| 论文方向 | 生产模型 | 系统用途 | 上线前验证 |
|---|---|---|---|
| Maher Poisson | maher_poisson_v1 | 生成比分矩阵 | Brier/Log Loss/比分分布校验 |
| Dixon-Coles | dixon_coles_v1 | 低比分和平局修正 | 0:0/1:0/0:1/1:1校准 |
| Bivariate Poisson | bivariate_poisson_v1 | 进球相关性 | 对比独立Poisson |
| Shin | shin_prob_v1 | 赔率去水 | 与简单归一化对比 |
| Favourite-Longshot Bias | flb_adjust_v1 | 热门/冷门偏差 | 分赔率区间ROI与校准 |
| Kelly | bankroll_fractional_kelly_v1 | 资金管理 | 回撤与破产概率模拟 |

## 生产规则
1. 没有 paper_key 的模型不得进入正式推荐；
2. 预印本或未复现模型只能放实验池；
3. 任何论文结论必须在本系统数据上 walk-forward 验证；
4. 模型有效性同时看概率指标和资金指标；
5. 不允许用单周收益证明模型有效。
