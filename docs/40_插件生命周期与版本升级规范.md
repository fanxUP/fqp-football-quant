# 40. 插件清单的现有校验边界

当前 `scripts/modules/plugin_validator.py` 是清单校验器，不是插件安装、隔离运行或灰度发布平台。

## 保留规则

1. 使用插件清单校验器时提供 plugin_id、name、type、module、version、status、entrypoint。原因：这些字段属于校验器的 REQUIRED 集合。
2. status 使用 draft、registered、experimental、staging、active、deprecated 或 removed。原因：校验器只接受这些值，它们不是自动执行的生命周期步骤。
3. active 插件声明 tests，active 的 model 插件另声明 backtest_report_id。原因：校验器检查这些字段存在，但不会执行测试或验证报告内容。
4. 维护扩展时保护认证、审计、官方数据和推荐审核入口。原因：清单校验不能拦截插件代码对这些能力的直接修改。
5. 对已有调用者、数据库和历史模型/回测结果说明兼容性与回退方式。原因：清单版本号不能自动迁移数据或恢复历史结果。
6. 启停、测试和发布以当前任务授权与真实入口为准。原因：当前没有通用插件热加载、灰度启用或自动回滚机制。
