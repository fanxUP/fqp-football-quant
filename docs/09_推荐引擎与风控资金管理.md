# 09_推荐引擎与风控资金管理

## 推荐引擎输入
- 官方赛程；
- 官方赔率快照；
- 市场去水概率；
- 模型概率；
- 模型委员会一致性；
- 数据完整度；
- 风险标签；
- 当日资金状态；
- 用户近期执行纪律。

## 推荐打分
```text
综合评分 = EV得分*35% + 置信度*20% + 模型一致性*15% + 赔率稳定性*10% + 数据完整度*10% + 联赛可信度*5% - 风险惩罚*5%
```

## 每日500元预算
- 主策略池：300元；
- 价值池：100元；
- 防守池：50元；
- 实验池：50元。

## 投入公式
```text
raw_kelly = (p * odds - 1) / (odds - 1)
fractional_kelly = max(0, raw_kelly) * 0.25
stake = min(每日剩余预算, 单票上限, 单场暴露剩余额度, 策略池剩余额度 * fractional_kelly)
```

## 熔断规则
1. 官方源异常；
2. 赔率快照缺失；
3. 数据完整度低；
4. 模型委员会分歧大；
5. EV经不确定性惩罚后小于阈值；
6. 连续亏损达到阈值；
7. 日内已用预算超限；
8. 用户偏离率过高。

## 推荐输出必须包含
- 比赛编号；
- 玩法；
- 选项；
- 官方SP；
- 模型概率；
- 市场概率；
- EV；
- 风险等级；
- 建议金额；
- 模型版本；
- 赔率快照时间；
- 失效条件。
