# 13_运维部署与长期个人运行

## 当前部署方式

- 本项目只使用 macOS 本机原生运行，不依赖 Docker Desktop。
- Homebrew PostgreSQL 18 在 `127.0.0.1:5432` 运行，`fqp` 是唯一业务数据库。
- Homebrew Redis 在 `127.0.0.1:6379/0` 运行。
- `com.fqp.local-stack` 同时监管前端、后端、Worker 和 Scheduler，支持登录自启和子进程异常恢复。
- Worker 是赔率高频任务的唯一执行者，Scheduler 负责日程调度，不重复轮询。
- 数据库每日全量备份，恢复演练结果单独记录；历史失败记录不删除。

安装和启动命令以 [54_本机运行与DockerDesktop弃用说明.md](54_本机运行与DockerDesktop弃用说明.md) 和 [../ops/local/README_LOCAL_RUNTIME.md](../ops/local/README_LOCAL_RUNTIME.md) 为准。

## 每日任务

00:05 初始化业务日期；00:10 采集赛程；06:00 早盘赔率；09:00 早盘模型；12:00 午盘赔率；16:00 正式候选；停售前 30 分钟最终快照；赛后结算；次日 08:00 日报。

## 监控指标

- 官方源成功率、赔率快照缺失率、赛果结算准确率；
- 推荐生成失败次数、任务队列积压、报表生成成功率；
- 数据库备份成功率、恢复演练成功率和磁盘空间。

## 异常处理

- 官方源失败、赔率不完整或模型校验失败：暂停正式推荐。
- 数据库异常：停止写入并告警，从 `data/backups/` 已验证备份恢复。
- 任一应用进程崩溃：由本机守护进程独立重启；连续失败时检查 `.runtime/` 日志。
- 备份失败：告警并阻止数据清理任务。
