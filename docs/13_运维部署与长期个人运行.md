# 13_运维部署与长期个人运行

## 部署方式

- 日常开发：macOS 宿主机进程 + 本机 PostgreSQL，使用 `./ops/local/run_local_dev.sh`；
- 发布运行：`./ops/local/run_local_stack.sh deploy` 先推送并核验 GitHub SHA，再由 Docker Desktop Compose 运行 postgres、redis、backend、frontend、worker、scheduler 与 Grafana；
- 本机 Scheduler 与 Docker Scheduler 为互斥模式，发布栈运行时不得再启动 `launchd` Scheduler；
- 服务器版：Nginx 反向代理 + HTTPS + 定时备份（后续扩展，不是当前默认）；
- 数据备份：每日全量、每小时增量、票据图片独立备份。

当前操作命令以 `54_本机运行与DockerDesktop弃用说明.md` 和 `../ops/local/README_Codex_Docker_Desktop.md` 为准。

## 每日任务
00:05 初始化业务日期；00:10 采集赛程；06:00 早盘赔率；09:00 早盘模型；12:00 午盘赔率；16:00 正式候选；停售前30分钟最终快照；赛后结算；次日08:00日报。

## 监控指标
- 官方源成功率；
- 赔率快照缺失率；
- 赛果结算准确率；
- 推荐生成失败次数；
- 报表生成成功率；
- 数据库备份成功率；
- 任务队列积压；
- 磁盘空间。

## 异常处理
- 官方源失败：暂停正式推荐；
- 数据库异常：停止写入并报警；
- 赔率缺失：该场比赛禁止推荐；
- 模型异常：切换到市场概率基线或只模拟；
- 备份失败：报警并阻止数据清理任务。
