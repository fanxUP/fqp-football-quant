# P08b：战术阵型示意

比赛详情 → 阵容与伤停 → 战术阵型示意。主客队切换共用一个可见时懒加载的 Canvas，俯视/2.5D、按钮镜头、画质、重置与二维关闭功能可用。二维球员按钮及三维节点共同选择真实球员，摘要显示名字、位置、角色与名单身份；替补与其他名单保留二维操作。

## 证据规则

- 已知 confirmed / predicted / historical 类型、来源、可解析时间、正快照 ID、准确比赛和球队 ID、11 名不同首发、1 名门将，以及后卫/中场/前锋分区全部存在，才生成示意。
- 位置采用快照 position；仅该值为空时才采用 primary_position。未识别或冲突类别不猜测，不从角色/号码/预测概率生成位置。类别映射为显式白名单，不是通用阵型解析器。
- 四个位置分区采用固定示意纵向距离，组内按 ID 稳定排序。左右顺序不代表实际侧别；来源报告阵型只作为文本，不改变类别布局。号码、真实坐标、热图和轨迹均未提供。
- 预估和历史名单仍明确标为相应类型，不声称已确认首发。来源确认标记未经平台独立认证。时区缺失保留原始快照时钟。
- 手动读取，无后台轮询或模型调用。失败保留同场成功数据并显示错误；有效空数据撤除场景和选择；换比赛隔离；同队仍存在的球员选择可跨快照保留。

## 场景生命周期

复用 SceneViewport、Pitch、CameraRig、主题 Token 和 RenderCounters。按需渲染，隐藏/离屏停用渲染和镜头，主动关闭卸载。上下文中断/加载错误局部回退二维名单；重试重建场景。共享几何和材质单一所有者负责 dispose，Pitch 子对象由 Fiber 管理。最多一个 Canvas，无自动旋转和持续动画，不新增依赖/API/数据库变化。

## 验证口径

实际结果以本阶段 .vibe/EVIDENCE.json 与 NAS V3f-EVIDENCE.json 为准。浏览器使用标注“界面测试”的合成名单；软件 WebGL 的能力检测仅在测试脚本中放宽。软件计数不是实际显存、FPS 或两小时实机耐久结论。生产覆盖不足会显示真实空态，未为满足演示补造阵容。
