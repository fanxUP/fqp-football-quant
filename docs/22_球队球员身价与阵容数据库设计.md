# 22 球队球员身价与阵容数据库设计

## 1. 模块目标

本模块负责把球队和球员身价、赛季阵容、关键球员、近期出场、替补深度转为结构化数据。其目标不是“身价高就一定赢”，而是把身价作为纸面实力、阵容深度和缺阵损失的量化代理变量。

身价数据必须谨慎使用。市场身价受年龄、合同、联赛曝光、国籍、商业价值、转会市场环境影响，不等于即时竞技能力。因此系统采用以下原则：

```text
身价是辅助特征，不是胜率本身。
总身价不如首发身价重要。
首发身价不如位置完整度和近期出场状态重要。
缺阵身价要结合近期出场占比和位置权重。
```

## 2. players：球员主表

球员主表保存稳定身份信息：

- 中文名；
- 英文名；
- 出生日期；
- 国籍；
- 主位置；
- 副位置；
- 惯用脚；
- 身高。

不得在主表中保存当前球队、当前身价、当前伤病，因为这些都随时间变化。

## 3. player_season_profiles：球员赛季画像表

此表表示一名球员在某支球队、某个赛事赛季中的状态。

关键字段：

### 注册与角色

- 球衣号码；
- 主要位置；
- 角色类型：主力、轮换、替补、青年队；
- 是否外租；
- 合同到期时间。

### 身价

- 当前身价；
- 币种；
- 队内身价排名；
- 身价更新时间；
- 数据源置信度。

### 比赛贡献

- 出场次数；
- 首发次数；
- 出场分钟；
- 进球；
- 助攻；
- 黄牌；
- 红牌。

### 近期状态

- 近 5 场首发数；
- 近 5 场出场分钟；
- 近 10 场首发数；
- 近 10 场出场分钟；
- 首发概率；
- 关键球员评分。

## 4. 球队身价特征

从球员赛季画像聚合出球队赛季画像。

建议计算：

```text
team_total_market_value = 所有一线队球员身价总和
team_avg_market_value = 平均身价
team_median_market_value = 中位数身价
top_5_market_value = 队内前5身价球员总和
top_11_market_value = 理论最强11人身价总和
squad_depth_value = 非前11球员身价总和
```

落地要求：

1. 使用 log 处理身价差，避免豪门对弱队时数值过度放大。
2. 联赛内比较优先于跨联赛绝对比较。
3. 跨联赛比赛必须加入联赛强度修正。
4. 国家队比赛要按国家队可用阵容计算，不使用俱乐部总身价直接替代。

## 5. 比赛层面身价特征

比赛预测真正需要的是本场可用阵容身价。

```text
home_team_value
away_team_value
home_available_value
away_available_value
home_starting_11_value
away_starting_11_value
home_bench_value
away_bench_value
starting_11_value_diff
bench_value_diff
key_player_absence_value_loss
```

推荐使用对数差：

```text
value_diff_log = log(home_starting_11_value + 1) - log(away_starting_11_value + 1)
```

## 6. 阵容深度评分

替补深度对下半场、让球、体能衰减很重要。

```text
squad_depth_score =
替补身价分 × 30%
替补近期出场分 × 25%
位置覆盖完整度 × 25%
年轻球员可用性 × 10%
替补进攻贡献 × 10%
```

## 7. 关键球员评分

关键球员不能只看身价，还要看近期出场和位置重要性。

```text
key_player_score =
近期出场分钟占比 × 30%
首发稳定性 × 20%
球队身价占比 × 20%
位置稀缺度 × 15%
进攻/防守贡献 × 15%
```

位置稀缺度示例：

- 主力门将：高；
- 主力中卫：高；
- 核心后腰：高；
- 主力中锋：高；
- 边锋：中；
- 替补边后卫：低。

## 8. 数据质量规则

| 问题 | 处理方式 |
|---|---|
| 身价缺失 | 使用队内中位数估算，但标记低置信度 |
| 身价过旧 | 提高 uncertainty_score |
| 球员转会未同步 | 不进入正式推荐，进入校对队列 |
| 国家队阵容缺失 | 只使用已公布名单，不用俱乐部全量阵容代替 |
| 小联赛身价不完整 | 降低身价特征权重 |

## 9. 验收标准

1. 每支重点球队能生成球队赛季画像。
2. 每名球员能生成赛季画像。
3. 能聚合球队总身价、前 5 身价、前 11 身价、替补深度。
4. 能计算关键球员评分。
5. 能输出比赛双方首发身价差。
6. 身价数据必须包含 source、snapshot_time、confidence。
7. 身价缺失不能直接按 0 处理。
8. 身价特征必须进入 `match_feature_snapshots`。
