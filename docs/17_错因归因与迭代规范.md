# 17_错因归因与迭代规范

## 目标
每次错误必须转化为可迭代信息。

## 错因分类
### 模型类
- 过度自信；
- 平局低估；
- 让球判断错误；
- 比分尾部概率不足；
- 小联赛样本不足。

### 市场类
- 赔率临场跳变；
- 热门过热；
- 冷门噪声；
- 官方SP价值消失。

### 数据类
- 伤停缺失；
- 阵容轮换未捕捉；
- 第三方匹配错误；
- 比赛延期/取消处理错误。

### 执行类
- 用户改票；
- 加倍；
- 追单；
- 漏买；
- 非推荐票亏损。

## 迭代规则
- 同一错因连续出现3次，进入模型修正队列；
- 某玩法连续亏损超过阈值，降权或暂停；
- 某联赛样本表现长期为负，加入灰名单；
- 用户偏离率超过20%，日报提示执行纪律问题。
