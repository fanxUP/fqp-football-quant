# 赤焰量化指挥中心 V1

实施阶段：P01–P04。基线：`74ebae2b11a3abda78abe851d95d58ee418e742c`。分支：`feat/3d-command-center-v1`。

## 已实现

- 更新现有 `redline-quant` 主题，保留 ID、旧称、十二主题、预览/应用/取消与本地持久化机制。
- 全局状态栏显示真实业务日、总览来源与响应生成时间、服务可达性、任务报告运行数量及告警数量。响应生成时间不充当采集快照时间。
- 全局状态栏和首页共用总览与健康查询，避免各自定时重复请求；首次加载、失败、过期和保留上次数据分别处理。
- 首页增加赛事雷达、数字球场、所选赛事证据三栏；窄屏依次排列。保留资金池、ROI、实盘盈亏和原业务入口。
- 赛事入口来自现有官方未结束列表，上限 500 场。搜索、列表与场景共用所选 ID；场景最多 24 个节点，选中范围外的赛事仍纳入场景。
- 详情同时验证赛事 ID 与主客队名称，忽略已卸载选择的晚到响应。模型概率按模型、玩法与预测时间分组，零与缺失分开。
- 赔率使用现有 `/api/official/matches/{id}/odds-snapshots?limit=200`，展示最近记录中的胜平负、原始记录 ID、快照时间和开盘字段。每个选项各有独立记录 ID；相同时间仅用于展示分组，不能推断同一次采集。缺失选项不补造。
- 3D 包按场景可见性加载，支持 2.5D、俯视、自由视角、旋转、缩放、有限平移与重置，提供镜头按钮作为拖拽替代操作。
- 默认无自动旋转，按需绘制；页面隐藏或场景不可见时暂停。低/标准/高画质 DPR 为 1/1.5/2。
- 3D 颜色读取当前 CSS Token，跟随主题预览及切换。赛事柱与底圈共享几何体及材质，由单一组件管理释放。
- WebGL 2 不支持、性能检测不通过、场景加载异常、context lost 或用户关闭场景时保留完整二维赛事与证据操作。
- 侧栏、主题开关和账户操作采用 SVG 图标；原路由与运行时模块注册行为保持。
- 新增行为测试，更新相关布局与图标断言。构建、测试与浏览器结果记录在 `.vibe/EVIDENCE.json`。

## 依赖取舍

增加并固定 `three@0.186.1`、`@react-three/fiber@9.8.1`、开发类型 `@types/three@0.186.0`。React 19 使用 R3F 9，未使用 alpha 主版本。均为 MIT 许可证；运行依赖安全公告检查返回 0 项漏洞。

现有 CSS、公共组件、HTTP 客户端与后台刷新机制可满足 V1。没有引入额外 UI 框架、服务状态库、独立 Node 服务或 WebSocket。镜头采用 Three.js 自带 OrbitControls。

3D 独立构建块约 940 KB 原始、约 250 KB gzip，属于按需下载资源；未进入可见场景或持久化关闭 3D 时不下载。后续按实机证据决定进一步拆包，而不是将大块提前加载到所有业务页。

官方参考：[React / R3F 版本配对](https://r3f.docs.pmnd.rs/getting-started/introduction)、[按需绘制与共享资源](https://r3f.docs.pmnd.rs/advanced/scaling-performance)。
