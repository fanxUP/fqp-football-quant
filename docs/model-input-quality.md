# 模型输入质量修正（2026-10-24）

本批在现有 `main` 顺序开发，修正旧影子训练入口和球员评分占位值，属于整合路线图中训练输入修正与 P108 的事实清理切片。P108 的转会归属、注册资格、真实分钟和及时刷新尚需后续开发；P111/P112 的新模型与效果评审不在本批完成范围。

## 训练样本

`load_settled_pre_kickoff_dataset` 默认选取训练截止时刻前最新的最多 5,000 场合格比赛，然后按开球时间、比赛 ID 正序输出。相同时间按比赛 ID 稳定取舍，每场仍取兼容版本中最后一条赛前快照，并按快照 ID 处理时间相同的记录。

必须有 `final/confirmed` 赛果、双方非空且非负的比分，以及早于训练截止的官方赛果发布时间。未知发布时间、缺失比分、负数比分、未来比赛和不兼容快照均排除。真实 0:0 仍为平局。没有合格数据时返回无样本，由现有训练作业跳过并保留原工件。

`cutoff_at` 是与旧表 `TIMESTAMP` 一致的无时区业务时间，默认使用现有业务时钟；`max_matches` 可取 1–5,000。该上限是资源边界，不是证明样本量足够或参数最优。此入口读取已留存快照，不重建历史数据，也不替代 P106 的样本清单和每折重新拟合评价。

## 球员事实与评分

- 首发和替补身份、位置、阵型、伤停类型及原因继续保留。
- 来源未提供的身价、实际分钟、关键球员评分、替补质量、缺阵影响、阵容强度、轮换风险和球队健康评分保持 `NULL`。
- 没有可比名单时，阵型、门将和中卫组合是否变化保持未知，不默认记为未变化。
- 六项阵容评分必须具备全部有效分量和明确的联赛身价参照；缺阵评分也必须具备全部分量。保留现有规则公式并不表示其权重已经验证。
- 任一待评分缺阵球员的分量不足时，全队影响和关键缺阵人数为未知；旧的按位置生成的预存影响分不再充当新评分依据。经原读取契约确认的零伤停仍可产生真实零影响。
- 有名单只证明名单覆盖；轮换覆盖按双方实际有效轮换评分分别计算。未知轮换不增加完整度。

现有数据库字段允许这些空值，本批不需要结构迁移或历史数据改写。覆盖不足只使相关增强信号缺失，基础球队/市场路径继续遵守原有条件。

## 版本与上线影响

新特征使用 `observed-form/v3` / `v5_player_facts`，55 个数值字段的顺序不变。旧 `observed-form/v2` 工件只匹配旧 `v4_observed_form` 快照，历史记录不重新解释；当前训练和特征解释只读取新版本。

部署后需要自然积累新版赛前快照及其已公布赛果。样本不足时，受影响的影子训练会跳过；旧特征版本工件遇到新快照时跳过该影子信号，不自动升级或改成正式模型。P106 新 Maher 工件的自然训练与生产来源验收仍按原记录推进。
