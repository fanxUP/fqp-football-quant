## 阅读规则

1. 操作前将文档命令与当前脚本、配置及 Git 状态核对。原因：设计稿和历史验收描述的环境可能与当前工作树不同。
2. 开发任务采用 [31 号工作流](31_Codex开发工作流与提示词模板.md) 和 `templates/codex/`；相关模块规范按实际修改范围读取。原因：这些文件直接指导修改，避免把整套历史规划变成每次任务的前置条件。
3. 运行方式按 [54 号规范](54_本机运行与DockerDesktop弃用说明.md) 选择对应入口。原因：原生 macOS、服务器发布和本地容器探针的配置及数据边界不同。
4. 当前行为以应用代码、有效配置、数据库迁移和实际执行证据共同核实。原因：OpenAPI 草案、配置声明或测试文件的存在都不能单独证明某能力已经运行。
5. 保留历史设计和验收事实，引用时标明阶段、环境与提交。原因：历史证据有追溯价值，但不能作为当前已通过验证的证明。
6. 改变实际运行方式、数据边界、模块依赖或审核边界时，同步对应现行规范。原因：后续维护依赖这些规则选择操作入口。
