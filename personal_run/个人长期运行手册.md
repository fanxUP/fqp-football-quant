# 个人长期运行手册

## 每日流程
1. 早上查看官方赛程是否正常；
2. 查看早盘模型候选，不急于实票；
3. 下午查看正式候选和赔率变化；
4. 停售前确认最终方案；
5. 线下自购后上传票据；
6. 不追单，不超预算；
7. 次日查看复盘。

## 每周流程
- 查看周报；
- 检查玩法ROI；
- 检查用户偏离率；
- 检查是否需要防守模式。

## 每月流程
- 查看资金曲线；
- 查看最大回撤；
- 对比模型版本；
- 决定是否调整预算和玩法。

## 禁止行为
- 连亏后加倍；
- 超过500元预算；
- 忽略熔断提示；
- 私自把实验池改成主策略；
- 把单日红黑当作模型有效证明。
